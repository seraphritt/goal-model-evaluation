**1. Identify the actors mentioned in the text and classify them as robot / non‑robot.**

**2. Apply the zero‑robot exclusion rule.** The following statements describe actions with **no robot involved**, so they are **excluded from the goal model** (they remain only as narrative context/preconditions):
- "A nurse … can request a delivery" → triggers the mission, but is a human action.
- "The nurse inserts data about the sample in a track system" → human data-entry action.
- "Each sample before collection is identified with a barcode" → no agent stated, no robot implied.
- "laboratory personnel" picking the sample → explicit OR‑alternative to the robotic arm, but the human branch is dropped; only the robotic‑arm branch survives, so no OR node is built for this (it collapses to a single path).
- "authorized personnel" opening drawers → same treatment; only the "specific robots" branch is kept.

**3. Detect runtime structure (parallel / sequential / fallback).**
- No IF‑statements, no failure/exception/threshold‑triggered alternative is described anywhere → **FALLBACK is never used** in this model.
- "Lab samples should be transported … In the laboratory, the sample can be picked …" → explicit temporal order → **sequential**.
- "picks up samples, scans the barcode … sorts, and loads …" → explicit ordered list → **sequential**.
- Logging ("where/when picked") and time‑tracking ("collection → delivery") are stated in two independent sentences with no stated order or mutual dependency → modeled as **parallel**, and both run alongside the transport/processing flow since they span its whole duration → also **parallel** with the main flow.

**4. Avoid redundancy.** "Transport sample" and "secure locked drawers" express the same underlying intention (secure relocation) — merged into a single goal (G2) rather than duplicated.

**5. Respect minimum‑two‑children rule for every AND/OR decomposition**, and use leaf nodes ("‑") only where the text gives no further operational breakdown (this is why "track delivery time" ends as a leaf Query goal rather than being forced into an artificial single‑child decomposition).
