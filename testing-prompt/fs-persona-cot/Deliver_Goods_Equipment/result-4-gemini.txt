### Step-by-Step Reasoning & Analysis

1. **Mission Objective & Phases Decomposition**:
The core mission requires a robot (or multiple robots) to collect resources from storage and deliver them to a specified location. This overarching objective (**G1**) naturally decomposes into two sequential phases: the **Collection Phase** (**G2**) and the **Delivery Phase** (**G3**). Because delivery can only occur once resources are retrieved, these phases execute sequentially (`G2;G3`).
2. **Collection Phase Breakdown (`G2`)**:
* During collection, robots navigate to storage places, order them by estimated waiting time plus path, request resources, and wait for retrieval. This is modeled as a normal collection sequence (`G2.1`), which further breaks down into navigating to storage (**G2.1.1 / AT1**) followed by requesting and waiting (**G2.1.2 / AT2**).
* **Exception Handling (Fallback 1)**: If the robot's battery drops to 10% during collection, it must abort normal collection and execute low-battery handling (**G2.2 / AT3**), returning to the recharging station and reassigning the mission. This is captured using the `FALLBACK` operator: `FALLBACK(G2.1, G2.2)`.


3. **Delivery Phase Breakdown (`G3`)**:
* The delivery phase involves transporting resources to the specified location across multiple runs (**G3.1 / AT4**).
* **Exception Handling (Fallback 2 & 3)**: The mission description specifies two cascading exceptions during delivery:
1. If battery drops to 30%, the robot returns the resource to a checkpoint and reassigns the remaining task (**G3.2 / AT5**).
2. If returning to the checkpoint fails, an alert must be triggered and a report sent to the sector manager (**G3.3 / AT6**).


* Due to binary fallback rules, multiple exceptions are nested: `FALLBACK(FALLBACK(G3.1, G3.2), G3.3)`.


4. **Multi-Robot Parallelism & Locations**:
* When multiple items are required from different storages, multiple robots can operate in parallel to reduce completion time. Locations cited directly from the text include **storage**, **recharging station**, **checkpoint**, **specified location**, **sterile facilities**, **use destinations**, **laundry**, **storage rooms**, and **sector manager**.
