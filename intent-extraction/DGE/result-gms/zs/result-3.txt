## Goals

| Name | Text | Runtime | Goal Type | Target Condition / Enquired Information | Relation |
|---|---|---|---|---|---|
| **G1: Resource Request Resolved** | Resolve the request by collecting the required resources from storage and delivering them to the requesting agent, or by escalating an unrecoverable delivery failure. Classified as **Achieve** because it represents a desired future mission state. | **[;]** G2; G3; G4 | Achieve | Required resources are delivered to the specified location for the requesting agent, or an unrecoverable checkpoint-return failure is reported to the sector manager. | AND |
| **G2: Mission Context Known** | Obtain the information needed to execute the mission. Classified as **Query** because it enquires mission data before execution. | **[;]** AT1; AT2; AT3 | Query | Required resources, requesting agent, specified delivery location, storage places, waiting-time estimates, and path costs. | AND |
| **G3: Execution Strategy Selected** | Decide whether the mission should be executed by one robot or by multiple robots in parallel. Classified as **Query** because it enquires execution conditions before choosing a strategy. | **[;]** AT4; AT5 | Query | Whether multiple items from different storages exist and whether enough robots are available for parallel collect-deliver tasks. | AND |
| **G4: Resource Movement Executed** | Execute the selected collect-deliver strategy. Classified as **Perform** because the goal succeeds when one of the executable mission strategies is carried out. | **FALLBACK(G14,G5)** | Perform | N/A | OR |
| **G5: Single-Robot Collect-Deliver Completed** | Complete the mission using one assigned robot, including collection and delivery. Classified as **Achieve** because it aims to bring about the state where the resources are collected and delivered by the assigned robot workflow. | **[;]** G6; G9 | Achieve | The assigned single-robot workflow has completed collection and delivery, or safely transferred responsibility when required. | AND |
| **G6: Collection Phase Resolved** | Complete the collection phase or safely hand it over when the assigned robot has low battery. Classified as **Achieve** because it targets a resolved collection state. | **FALLBACK(G7,G8)** | Achieve | Resources are retrieved from storage, or the mission is reassigned after the robot returns to recharge. | OR |
| **G7: Resources Retrieved From Storage** | Retrieve the required resources from the relevant storage places. Classified as **Achieve** because the desired state is that the resources have been retrieved. | **[;]** AT6; AT7; AT8 | Achieve | Required resources have been requested from storage and retrieved. | AND |
| **G8: Collection Low-Battery Handover Completed** | Handle low battery during collection by returning the robot to recharge and assigning the mission to another robot. Classified as **Achieve** because it targets a safe continuation state after battery degradation. | **[;]** AT9; AT10 | Achieve | Robot with 10% battery returns to the recharging station and another robot is assigned to continue the mission. | AND |
| **G9: Delivery Phase Resolved** | Deliver the retrieved resources or safely handle low battery during delivery. Classified as **Achieve** because it targets completion or safe continuation of the delivery phase. | **FALLBACK(G10,G11)** | Achieve | Resources are delivered to the specified location, or delivery is safely handed over/escalated. | OR |
| **G10: Resources Delivered To Destination** | Move all retrieved resources to the specified delivery location, making as many runs as necessary. Classified as **Achieve** because the target state is that all resources are at the destination. | **[;]** AT11 | Achieve | All required resources are delivered to the specified location. | AND |
| **G11: Delivery Low-Battery Situation Resolved** | Handle low battery during delivery by checkpointing the resource and assigning the remaining task, or reporting failure if checkpointing fails. Classified as **Achieve** because it targets a resolved failure-contingency state. | **FALLBACK(G12,G13)** | Achieve | Resource is placed at a checkpoint and another robot receives the remaining task, or failure is escalated. | OR |
| **G12: Resource Checkpointed And Task Transferred** | Return the resource to a checkpoint and transfer the remaining delivery task to another robot. Classified as **Achieve** because it creates the state where another robot can continue from a known resource position. | **[;]** AT12; AT13 | Achieve | Resource is positioned at the checkpoint and another robot knows where it is. | AND |
| **G13: Checkpoint Failure Reported** | Trigger an alert and send a report to the sector manager if the robot fails to return the resource to a checkpoint. Classified as **Achieve** because the target state is that the failure has been formally escalated. | **[;]** AT14; AT15 | Achieve | Alert is triggered and failure report is sent to the sector manager. | AND |
| **G14: Parallel Collect-Deliver Completed** | Assign multiple robots to parallel collect-deliver tasks when multiple items are required from different storages. Classified as **Perform** because it represents the execution of a specific multi-robot strategy to reduce mission time. | **[#]** AT16 # AT17 # AT18 | Perform | N/A | AND |

## Tasks

| Name | Text | Relation | Location | Number of Robots |
|---|---|---|---|---|
| **AT1: Capture Resource Request** | Capture the required resources, requesting agent, and specified delivery location. | AND | request_interface | 1 |
| **AT2: Identify Storage And Destination** | Identify the storage places where the requested resources can be found and the final delivery location. | AND | storage_places, specified_location | 1 |
| **AT3: Estimate Waiting And Path Cost** | Estimate the waiting time at each storage and the path cost to be run by the robot. | AND | hospital_map, storage_places | 1 |
| **AT4: Check Multiple-Storage Demand** | Check whether multiple items are required from different storages. | AND | mission_control | 1 |
| **AT5: Check Available Robots** | Check whether multiple robots are available for parallel collect-deliver tasks. | AND | fleet_management_system | 1 |
| **AT6: Navigate To Storage Places** | Move the robot to the storage places where the resources can be found, following the selected order. | AND | storage_places | 1 |
| **AT7: Send Resource Request Message** | Send a message to the storage with the precise specification of the requested resources. | AND | storage_communication_interface | 1 |
| **AT8: Wait For Retrieval** | Wait at the storage until the requested resources have been retrieved. | AND | storage_places | 1 |
| **AT9: Return To Recharging Station** | If battery reaches 10% during collection, return the assigned robot to the recharging station. | AND | recharging_station | 1 |
| **AT10: Reassign Mission During Collection** | Assign the collection mission to another robot after the original robot returns to recharge. | AND | mission_allocation_system | 2 |
| **AT11: Execute Delivery Runs** | Make as many delivery runs as necessary to take all resources to the specified location. | AND | specified_location | 1 |
| **AT12: Return Resource To Checkpoint** | If battery reaches 30% during delivery, return the resource to a checkpoint. | AND | checkpoint | 1 |
| **AT13: Transfer Remaining Delivery Task** | Assign the remaining task to another robot and provide the known resource position. | AND | mission_allocation_system, checkpoint | 2 |
| **AT14: Trigger Failure Alert** | Trigger an alert if the robot fails to return the resource to a checkpoint. | AND | mission_control | 1 |
| **AT15: Send Failure Report** | Send the failure report to the sector manager. | AND | sector_manager_interface | 1 |
| **AT16: Split Items By Storage** | Divide requested items into collect-deliver subtasks according to their storage locations. | AND | mission_control, storage_places | [2,n] |
| **AT17: Assign Parallel Robots** | Assign multiple robots to parallel collect-deliver tasks. | AND | fleet_management_system | [2,n] |
| **AT18: Execute Parallel Collect-Deliver Runs** | Execute parallel collection and delivery runs to reduce mission completion time. | AND | storage_places, specified_location | [2,n] |
