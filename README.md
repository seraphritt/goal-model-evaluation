# Repositório para avaliação dos goal models gerados por LLMs

## Métricas de Avaliação:

**Métrica relacionada a RQ1: a avaliação é feita levando em consideração cada goal.**

**Métricas relacionadas a RQ2: a avaliação é holística, considera o goal model como um todo.**

- RQ1 - Goal type correctness: The goal type (query, achieve or perform) of a each goal is related to the mission specification. (nessa aqui a avaliação é feita levando em consideração cada goal)

- RQ2 - Goal Relevance : The outcome covers the relevant goals contained in the mission description. 

- RQ2 - Degree of Non-redundancy: This goal model does not include redundant goals/tasks, including their attributes, i.e., tasks that overlap in purpose with another goal/task and that could be removed without changing the model’s coverage.

- RQ2 - Granularity: This goal model is specified at a appropriate level of detail.

**Modo de avaliação: Escala Likert (1 - Strongly Disagree, 2 - Disagree, 3 - Undecided, 4 - Agree, 5 - Strongly Agree)**
