DEFINITIONS:
A goal model is a modeling structure which consists in the hierarchical decomposition
of goals into sub-goals and tasks, using a tree structure. There are two types of decompositions which are the (i)
OR decomposition, where the fulfillment of one child is sufficient for the fulfillment of the
parent, and the (ii) AND decomposition, where all childs need to be fulfilled in order for
the parent to be fulfilled. 

Every Goal and Task must have a AND/OR decomposition. 


Use the following definitions and the ones on the embedded file:

    Goal Node: A goal node represents an intentional system objective, it is not operational (unlike a task).

Format: GOAL_ID: GOAL_TEXT GOAL_RUNTIME_ANNOT

3.4 Goal Types

There are three goal types; each has specific requirements:

a. Perform Goal

    A perform goal is a goal type in which the agent (i.e. an entity that can perform actions in the World and initiate events or change some states in the World​) executes actions, when possible, without necessarily requiring that the state denoted by the goal is reached.  A perform goal requires that a specific action is executed. When no action could be performed the goal is has failed. Otherwise, the goal is successful.

b. Query Goal

    A query goal is a goal used to retrieve information about the World as the result of a query. Therefore, the goal does not necessarily cause the agent to engage in actions. Its main purpose is to obtain knowledge or data. A query goal succeeds when the agent has obtained all the information it was searching for.

c. Achieve Goal

    An achieve goal is a goal that contains a AchieveCondition, which represents the state that the agent intends to reach through planning and action. This target state is represented by an target condition. The agent plans and acts with the purpose of making the target condition true.
