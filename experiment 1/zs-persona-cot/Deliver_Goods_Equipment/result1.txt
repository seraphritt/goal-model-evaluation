## Logical Relationships

* **G1 -> G2, G6, G8, G11 [AND][sequential: `G2;G6;G8;G11`]**

* **G2 -> G3, G4, G5 [AND][parallel: `G3#G4#G5`]**

* **G6 -> AT1, G7 [AND][sequential: `AT1;G7`]**

* **G7 -> AT2, AT3 [OR][fallback: `FALLBACK(AT2,AT3)`]**
  Parallel assignment is preferred when multiple resources from different storages are involved; otherwise, the fallback is single-robot sequential assignment.

* **G8 -> G9, G10 [OR][fallback: `FALLBACK(G9,G10)`]**
  Normal collection is attempted first. If the robot reaches 10% battery during collection, the model falls back to low-battery recovery.

* **G9 -> AT4, AT5, AT6 [AND][sequential: `AT4;AT5;AT6`]**

* **G10 -> AT7, AT8 [AND][sequential: `AT7;AT8`]**

* **G11 -> G12, G13 [OR][fallback: `FALLBACK(G12,G13)`]**
  Normal delivery is attempted first. If the robot reaches 30% battery during delivery, the model falls back to delivery recovery.

* **G12 -> AT9, AT10, AT11 [AND][sequential: `AT9;AT10;AT11`]**

* **G13 -> G14, G15 [OR][fallback: `FALLBACK(G14,G15)`]**
  The robot first tries checkpoint-based recovery. If returning the resource to a checkpoint fails, the system escalates.

* **G14 -> AT12, AT13, AT14 [AND][sequential: `AT12;AT13;AT14`]**

* **G15 -> AT15, AT16 [AND][sequential: `AT15;AT16`]**
