## Goal Model — Resource Collection and Delivery Mission

### Goals

| Name                                              | Text                                                                                                                          |                             Runtime | Goal Type | Target Condition / Enquired Information                                                                              | Relation   |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------------------------------: | --------- | -------------------------------------------------------------------------------------------------------------------- | ---------- |
| **G1: Complete Resource Delivery Mission**        | Ensure that required resources are collected from storage and delivered to the requesting agent at the specified location.    |                       **G2;G5;G11** | Achieve   | Required resources are delivered to the requesting agent/location, or a failure is reported to the sector manager.   | Root / AND |
| **G2: Acquire Mission Request Data**              | Obtain the mission data needed to start the collect-deliver process.                                                          |                           **G3#G4** | Query     | Required resources, requesting agent, and delivery location.                                                         | AND        |
| **G3: Identify Required Resources**               | Query which resources are required by the requesting agent.                                                                   |                               **-** | Query     | List, quantity, and precise specification of required resources.                                                     | AND        |
| **G4: Identify Requesting Agent and Destination** | Query who requested the resources and where they must be delivered.                                                           |                               **-** | Query     | Requesting agent and specified delivery location.                                                                    | AND        |
| **G5: Plan Collection and Robot Allocation**      | Define where resources will be collected, in which order, and by which robot or robots.                                       |                        **G6;G7;G8** | Achieve   | A collection-delivery plan exists with storage locations, visit order, and robot assignment.                         | AND        |
| **G6: Locate Resource Storages**                  | Identify the storage places where the requested resources can be found.                                                       |                               **-** | Query     | Storage places containing the required resources.                                                                    | AND        |
| **G7: Determine Storage Visit Order**             | Determine the order in which storages should be visited based on waiting time and robot path.                                 |                               **-** | Query     | Ordered list of storages according to estimated waiting time plus travel path.                                       | AND        |
| **G8: Select Robot Assignment Strategy**          | Decide whether the mission should be executed by one robot or by multiple robots in parallel.                                 |                **FALLBACK(G9,G10)** | Achieve   | A suitable robot assignment strategy is selected.                                                                    | OR         |
| **G9: Assign Single Robot**                       | Assign one available robot to perform the collection and delivery mission.                                                    |                             **AT1** | Achieve   | One robot is assigned to the mission.                                                                                | OR         |
| **G10: Assign Multiple Robots in Parallel**       | Assign multiple robots to parallel collect-deliver tasks when resources come from different storages.                         |                         **AT2;AT3** | Achieve   | Resources are partitioned by storage and multiple robots are assigned to reduce mission time.                        | OR         |
| **G11: Execute Fulfillment Process**              | Execute the planned collection and delivery process.                                                                          |                         **G12;G15** | Achieve   | Collection phase and delivery phase are completed or safely handled through contingency procedures.                  | AND        |
| **G12: Complete Collection Phase**                | Ensure that the assigned robot or robots collect the required resources from storage, with contingency for low battery.       |               **FALLBACK(G13,G14)** | Achieve   | Resources are retrieved from storage, or collection is safely reassigned after low battery.                          | OR         |
| **G13: Perform Standard Storage Collection**      | Execute the normal resource collection procedure at the selected storage places.                                              |                 **AT4;AT5;AT6;AT7** | Achieve   | Required resources are requested, retrieved, and loaded by the robot.                                                | OR         |
| **G14: Handle Low Battery During Collection**     | If battery reaches 10% during collection, return to recharge and assign the mission to another robot.                         |                    **AT8;AT9;AT10** | Achieve   | Robot goes to the recharging station and the remaining collection mission is assigned to another robot.              | OR         |
| **G15: Complete Delivery Phase**                  | Ensure that collected resources are delivered to the specified location, with contingency for low battery or handoff failure. | **FALLBACK(G16,FALLBACK(G17,G18))** | Achieve   | Resources are delivered, or the remaining delivery is reassigned through checkpoint handoff, or failure is reported. | OR         |
| **G16: Perform Standard Resource Delivery**       | Deliver the collected resources to the requesting agent at the specified location.                                            |             **AT11;AT12;AT13;AT14** | Achieve   | All required resources are delivered to the requesting agent/location.                                               | OR         |
| **G17: Handle Low Battery During Delivery**       | If battery reaches 30% during delivery, return the resource to a checkpoint and assign the remaining task to another robot.   |                  **AT15;AT16;AT17** | Achieve   | Resource is placed at a checkpoint and another robot is assigned with knowledge of the checkpoint position.          | OR         |
| **G18: Report Checkpoint Return Failure**         | If returning the resource to a checkpoint fails, trigger an alert and send a report to the sector manager.                    |                       **AT18;AT19** | Perform   | Alert is triggered and failure report is sent to the sector manager.                                                 | OR         |

## Tasks

| Name                                              | Text                                                                                             | Relation | Location                                | Number of Robots |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------ | -------- | --------------------------------------- | ---------------: |
| **AT1: Reserve Assigned Robot**                   | Reserve one available robot to execute the mission.                                              | OR       | robot_base / hospital                   |                1 |
| **AT2: Partition Resources by Storage**           | Divide the required resources into groups according to their storage locations.                  | AND      | mission_control / hospital              |                1 |
| **AT3: Reserve Parallel Robot Team**              | Reserve multiple robots to execute collect-deliver tasks in parallel.                            | AND      | robot_base / hospital                   |            [2,n] |
| **AT4: Navigate to Storage**                      | Robot goes to the storage place according to the planned visit order.                            | AND      | storage_places                          |            [1,n] |
| **AT5: Send Resource Request Message**            | Robot sends a message to the storage with the precise specification of the requested resources.  | AND      | storage_place                           |            [1,n] |
| **AT6: Wait for Resource Retrieval**              | Robot waits until the storage retrieves the requested resources.                                 | AND      | storage_place                           |            [1,n] |
| **AT7: Load Retrieved Resources**                 | Robot receives and loads the retrieved resources for transport.                                  | AND      | storage_place                           |            [1,n] |
| **AT8: Navigate to Recharging Station**           | Robot returns to the recharging station after reaching 10% battery during collection.            | AND      | recharging_station                      |                1 |
| **AT9: Transfer Collection Mission State**        | Robot or system records remaining resources, current storage progress, and mission status.       | AND      | mission_control / recharging_station    |                1 |
| **AT10: Assign Replacement Robot for Collection** | Another robot is assigned to continue the remaining collection mission.                          | AND      | robot_base / hospital                   |                1 |
| **AT11: Navigate to Delivery Location**           | Robot transports collected resources toward the specified delivery location.                     | AND      | delivery_route / specified_location     |            [1,n] |
| **AT12: Perform Required Delivery Runs**          | Robot makes as many runs as necessary to move all resources to the destination.                  | AND      | storage_to_destination_route            |            [1,n] |
| **AT13: Deliver Resources to Requesting Agent**   | Robot delivers the resources to the requesting agent at the specified location.                  | AND      | specified_location                      |            [1,n] |
| **AT14: Confirm Delivery Completion**             | Robot confirms that the resources were delivered successfully.                                   | AND      | specified_location                      |            [1,n] |
| **AT15: Move Resource to Checkpoint**             | Robot returns the resource to a checkpoint after reaching 30% battery during delivery.           | AND      | checkpoint_location                     |                1 |
| **AT16: Register Checkpoint Position**            | Robot records the checkpoint location and the position of the resource.                          | AND      | checkpoint_location / mission_control   |                1 |
| **AT17: Assign Replacement Robot for Delivery**   | Another robot is assigned to complete the remaining delivery task using the checkpoint position. | AND      | robot_base / checkpoint_location        |                1 |
| **AT18: Trigger Failure Alert**                   | System triggers an alert when the robot fails to return the resource to a checkpoint.            | AND      | mission_control / hospital              |                1 |
| **AT19: Send Report to Sector Manager**           | System sends a failure report to the sector manager.                                             | AND      | mission_control / sector_manager_office |                1 |

* **G8 -> G9, G10 [OR][FALLBACK(G9,G10)]**

* **G9 -> AT1 [AND][sequential: AT1]**

* **G10 -> AT2, AT3 [AND][sequential: AT2;AT3]**

* **G11 -> G12, G15 [AND][sequential: G12;G15]**

* **G12 -> G13, G14 [OR][FALLBACK(G13,G14)]**
