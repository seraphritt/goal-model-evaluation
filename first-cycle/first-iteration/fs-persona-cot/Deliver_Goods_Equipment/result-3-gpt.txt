## Interpretation choices

The main mission is: collect required resources from storage and deliver them to the requesting agent at the specified location. Collection includes going to storage places, ordering visits by waiting time plus robot path, sending a precise request, and waiting for retrieval. Texto colado

The delivery phase begins after retrieval and may require multiple runs. Battery-related recovery differs by phase: at **10%** during collection, the robot returns to the recharging station and reassigns the mission; at **30%** during delivery, the robot returns the resource to a checkpoint and reassigns the remaining task. Texto colado

For checkpoint-return failure, the description only states that an alert and report to the sector manager must occur; it does **not** specify a successful delivery recovery after that failure. Texto colado

## Logical relationships

- **G1 -> G2, G8, G11, G16 [AND][sequential: `G2;G8;G11;G16`]**  
  **Justification:** The mission must first determine the itinerary, select robot allocation, collect resources, and then deliver them. Collection precedes delivery because delivery begins once resources are retrieved. Texto colado

- **G2 -> G3, G4, G7 [AND][sequential: `G3;G4;G7`]**  
  **Justification:** The system needs to know the storage places, estimate waiting/path values, and then define the storage order using those estimates. Texto colado

- **G4 -> G5, G6 [AND][parallel: `G5#G6`]**  
  **Justification:** Waiting time and path are both inputs to the ordering criterion, and the description does not require one to be estimated before the other. Texto colado

- **G8 -> G9, G10 [OR][selection]**  
  **Justification:** The description implies a normally assigned robot, but also states that multiple robots can be assigned to parallel collect-deliver tasks when resources come from different storages. Since no first/second order is given, this is OR, not FALLBACK. Texto colado

- **G11 -> G12, G15 [AND][fallback: `FALLBACK(G12,G15)`]**  
  **Justification:** Normal collection is attempted first. If the assigned robot reaches 10% battery during collection, it must return to the recharging station and assign the mission to another robot. Texto colado

- **G12 -> G13, G14 [AND][sequential: `G13;G14`]**  
  **Justification:** The robot must first reach the storage, then request and wait for the resources. Texto colado

- **G14 -> AT2, AT3 [AND][sequential: `AT2;AT3`]**  
  **Justification:** The message with precise resource specification must be sent before waiting for retrieval. Texto colado

- **G15 -> AT4, AT5, AT6 [AND][sequential: `AT4;AT5;AT6`]**  
  **Justification:** The low-battery collection robot returns to the recharging station, the mission is reassigned, and another robot continues the mission. Texto colado

- **G16 -> G17, G18 [AND][fallback: `FALLBACK(G17,G18)`]**  
  **Justification:** Normal delivery is attempted first. If battery reaches 30% during delivery, checkpoint handoff and reassignment are required. Texto colado

- **G17 -> AT7 [AND][single delivery execution]**  
  **Justification:** The robot must make as many runs as necessary to take all resources to the specified location. Texto colado

- **G18 -> G19, G20 [AND][fallback: `FALLBACK(G19,G20)`]**  
  **Justification:** The robot first attempts checkpoint handoff. If returning the resource to the checkpoint fails, alert and report are required. Texto colado

- **G19 -> AT8, AT9, AT10 [AND][sequential: `AT8;AT9;AT10`]**  
  **Justification:** The resource must be returned to a checkpoint, the remaining task assigned to another robot, and that robot must know the resource position. Texto colado
