## 1. Modeling assumptions used

The root mission has two main capabilities: deliver meals and retrieve dirty dishes. These are modeled as AND because the description states both that food should be delivered and dirty dishes should be retrieved. Texto colado

I used OR where the description gives alternatives, such as table delivery versus tray retrieval, or unassisted dish retrieval versus cooperative retrieval. The file defines OR as one child being sufficient and AND as all children being required. Texto colado

I avoided FALLBACK for delivery-method choices because the description does not explicitly impose an order such as “try tray retrieval first, then table placement.” The file says FALLBACK must be used only when the description explicitly specifies the order or an exception/failure-triggered alternative.
