Below is a source-grounded goal model for the multi-robot resource collection and delivery mission. I use the mission’s own concepts: **storage**, **storage places**, **specified location**, **requesting agent**, **recharging station**, **checkpoint**, and **sector manager**. The model treats collection before delivery as sequential because the delivery phase begins only once resources have been retrieved. Texto colado

## Modeling rationale

The root mission is to ensure that required resources are collected from storage and delivered to the requesting agent at a specified location. The collection phase includes visiting storage places, ordering visits by waiting-time estimate plus robot path, sending a precise resource request, and waiting for retrieval. Texto colado

Battery contingencies are modeled with **FALLBACK** because the description explicitly defines normal behavior and alternative behavior triggered by thresholds: **10% battery in collection** and **30% battery in delivery**. Texto colado Parallelism is represented where multiple items from different storages allow multiple robots to execute collect-deliver workstreams in parallel. Texto colado

## Logical Relationships

**G1 → G2, G5, G6, G11 [AND][sequential: `G2;G5;(G6;G11)`]**  
- **Justification:** The mission first needs parameters, then robot assignment, then collection, then delivery. Collection precedes delivery because delivery begins once resources are retrieved. Texto colado

**G2 → G3, G4 [AND][sequential: `G3;G4`]**  
- **Justification:** The system must know the requested resources and destination before computing the order of storage visits.

**G5 → AT1, AT2 [AND][parallel: `AT1#AT2`]**  
- **Justification:** Robot assignment is required, and parallel workstream assignment may occur when multiple items from different storages are involved. This uses parallelism rather than OR because the source describes parallel execution, not alternative mission satisfaction. Texto colado

**G6 → G7, G10 [AND][fallback: `FALLBACK(G7,G10)`]**  
- **Justification:** Normal collection is attempted first. If the robot reaches 10% battery during collection, the recovery behavior is triggered: go to recharge and reassign the mission. Texto colado

**G7 → G8, G9 [AND][sequential: `G8;G9`]**  
- **Justification:** The robot must first reach the relevant storage places and then request and obtain the resources.

**G8 → AT3 [AND]**  
- **Justification:** Traveling to storage places operationalizes the goal of reaching the storages where resources are found.

**G9 → AT4, AT5 [AND][sequential: `AT4;AT5`]**  
- **Justification:** The robot first sends the precise resource specification and then waits until the resources are retrieved. Texto colado

**G10 → AT6, AT7 [AND][sequential: `AT6;AT7`]**  
- **Justification:** When collection battery is low, the robot goes to the recharging station and assigns the mission to another robot.

**G11 → G12, G14 [AND][fallback: `FALLBACK(G12,G14)`]**  
- **Justification:** Normal delivery is attempted first. If the delivery robot reaches 30% battery, checkpoint handoff recovery is triggered. Texto colado

**G12 → AT8 [AND]**  
- **Justification:** Delivery is operationalized by making as many runs as necessary to transport all resources to the specified location.

**G13 → AT9 [AND][parallel]**  
- **Justification:** Parallel collect-deliver tasks are used when multiple items from different storages can be handled by multiple robots. Texto colado

**G14 → G15, G16 [AND][fallback: `FALLBACK(G15,G16)`]**  
- **Justification:** The intended delivery recovery is checkpoint handoff. If returning the resource to a checkpoint fails, the fallback is alerting and reporting.

**G15 → AT10, AT11 [AND][sequential: `AT10;AT11`]**  
- **Justification:** The resource must first be returned to the checkpoint; then another robot can be assigned with knowledge of the resource position.

**G16 → AT12, AT13 [AND][sequential: `AT12;AT13`]**  
- **Justification:** The description requires both triggering an alert and sending a report to the sector manager when checkpoint return fails. Texto colado
