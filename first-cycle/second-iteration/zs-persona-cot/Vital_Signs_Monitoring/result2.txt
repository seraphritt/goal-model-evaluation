**Mission-analysis rationale (summary):**

* The mission is primarily an **Achieve-oriented mission** because the desired state is that all required patients have their vital signs checked according to constraints (time, risk, safety, and recovery conditions).
* Some sub-goals are **Query goals** because the robot must obtain information from the environment (e.g., patient availability, patient identity, required measurements).
* Some sub-goals are **Perform goals** because they require execution of actions (e.g., visiting rooms, collecting measurements, sterilizing robots).
* Parallel execution is used where activities can happen independently (e.g., high-risk prioritization and resource management).
* Sequential execution is used where the mission description imposes order (e.g., identify patient → enter room → perform measurement → mark completed).
* Fallback is used where the mission specifies an alternative action after failure (e.g., patient unavailable → retry later; insufficient battery → recharge and reassign).
