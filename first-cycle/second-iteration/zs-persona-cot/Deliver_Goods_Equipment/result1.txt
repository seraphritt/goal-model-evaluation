I use **AND** when all children are required, **OR** only where alternatives would be sufficient, and **FALLBACK** only where the description explicitly says one behavior happens when another cannot be completed or fails. The mission explicitly defines collection before delivery, battery-triggered handover, checkpoint failure reporting, and optional parallel collect-deliver tasks for multiple items from different storages. ## Modeling rationale

The mission has four main phases:

1. **Understand the request**: required resources, storage places, requesting agent, and specified destination.
2. **Plan execution**: order storages by waiting-time estimation plus path, and assign one or more robots.
3. **Collect resources**: go to storage, request the precise resources, and wait until retrieved.
4. **Deliver resources**: perform as many runs as needed, with battery-contingency behavior during collection and delivery.

The model uses **FALLBACK** for low-battery or failure situations because the provided definition says fallback is used when a second goal is attempted only if the first cannot be achieved; it also states fallback-connected sub-goals are connected by an AND decomposition. Texto colado

# Logical Relationships

- **G1 -> G2, G3, G4 [AND][sequential: `G2;G3;G4`]**  
  - **Justification:** The mission cannot be fulfilled unless the request is understood, the execution is planned, and the collect-deliver work is completed. The source defines AND decomposition as requiring all children for the parent to be fulfilled. Texto colado

- **G2 -> AT1, AT2 [AND][sequential: `AT1;AT2`]**  
  - **Justification:** The robot needs both the request details and the storage places before planning the collection.

- **G3 -> AT3, AT4 [AND][sequential: `AT3;AT4`]**  
  - **Justification:** Storage order must be defined before robot assignment can be operationally meaningful. The order depends on waiting time plus path, while assignment may use multiple robots for items from different storages. Texto colado Texto colado

- **G4 -> G5, G8 [AND][sequential per batch: `G5;G8`; parallel across batches: `((G5_i;G8_i)#...#(G5_n;G8_n))`]**  
  - **Justification:** Delivery begins only once resources are retrieved, but multiple collect-deliver tasks may run in parallel when resources come from different storages. Texto colado

- **G5 -> G6, G7 [AND][fallback: `FALLBACK(G6,G7)`]**  
  - **Justification:** Normal collection is attempted first. If collection cannot continue because battery is low at 10%, the robot returns to recharge and reassigns the mission.

- **G6 -> AT5, AT6, AT7 [AND][sequential: `AT5;AT6;AT7`]**  
  - **Justification:** Collection requires traveling to storage, sending a precise request, and waiting for retrieval. Texto colado

- **G7 -> AT8, AT9 [AND][sequential: `AT8;AT9`]**  
  - **Justification:** The low-battery collection response requires both returning to the recharging station and assigning the mission to another robot. Texto colado

- **G8 -> G9, G10 [AND][fallback: `FALLBACK(G9,G10)`]**  
  - **Justification:** Normal delivery is attempted first. If delivery cannot continue because battery reaches 30%, the robot performs checkpoint-based handover. Texto colado

- **G9 -> AT10, AT11 [AND][sequential: `AT10;AT11`]**  
  - **Justification:** The robot must deliver resources and continue making runs as needed until all resources are taken to the specified location. Texto colado

- **G10 -> G11, G12 [AND][fallback: `FALLBACK(G11,G12)`]**  
  - **Justification:** The robot first tries to return the resource to a checkpoint and reassign the remaining task. Only if checkpoint return fails does it trigger an alert and send a report. Texto colado

- **G11 -> AT12, AT13 [AND][sequential: `AT12;AT13`]**  
  - **Justification:** The resource must be placed at a checkpoint, and the remaining task must be assigned to another robot that knows the resource position.

- **G12 -> AT14, AT15 [AND][sequential: `AT14;AT15`]**  
  - **Justification:** In checkpoint-return failure, both alert triggering and report sending are mandatory.
