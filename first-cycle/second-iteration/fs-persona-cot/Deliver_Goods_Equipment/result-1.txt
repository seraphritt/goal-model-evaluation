	## Mission Interpretation

	The mission is to collect requested resources from storage places and deliver them to a requesting agent at a specified location. The collection phase requires visiting storage places, ordering visits by estimated waiting time plus robot path, requesting the resources through a message, and waiting for retrieval. After retrieval, the delivery phase begins and may require several delivery runs. Battery-related exceptions are phase-dependent: 10% in collection leads to recharging and mission reassignment, while 30% in delivery leads to checkpoint handling and reassignment; if checkpoint return fails, an alert and report are sent to the sector manager. Multiple robots may be assigned in parallel when resources come from different storages. :chatgpt-content-reference{index="0"}

	The model uses **AND decomposition** for jointly required mission steps and **FALLBACK** only where the description explicitly states a failure alternative: failure to return the resource to a checkpoint triggers alert/report handling. This follows the provided fallback definition. :chatgpt-content-reference{index="1"}

	## Notes on Modeling Choices

	1. **Most decompositions are AND**, because the mission description mainly specifies required complementary actions rather than alternatives.
	2. **Parallel execution is used only for multiple storage/item situations**, because the description explicitly states that multiple robots can be assigned to parallel collect-deliver tasks.
	3. **Fallback is used only once**, for checkpoint-return failure, because that is the only place where the mission explicitly says what happens if a prior action fails.
	4. **Locations are not invented**. They are derived from the mission description: `storage_places`, `specified_location`, `recharging_station`, `checkpoint`, and `sector_manager`.
	5. **Robot numbers are conservative**. Single assigned-robot actions use `1`; parallel multi-storage tasks use `[1,n]`, where `n` represents the available robots assigned to different collect-deliver tasks.
