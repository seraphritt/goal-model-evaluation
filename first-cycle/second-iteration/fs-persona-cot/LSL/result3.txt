## 1. Modeling rationale and scope

### Robot-performed elements kept in the goal model
The mission description contains both human and robot activities. Because the instruction says that goals/tasks not performed by any robot must not be in the goal model, I keep only robot-executed objectives and tasks:

- **Mobile delivery robot**: receives/uses delivery request information, carries samples in locked drawers from **patient floors** to the **laboratory**, monitors lock state and timing.
- **Authorized drawer-opening robot / drawer mechanism**: opens locked drawers only when robot identity and location are valid.
- **Laboratory robotic arm**: picks samples, scans barcodes, sorts them, loads them into the **entry-module of analysis machines**, and logs pickup information.

### Human-only activities excluded
The following are mission context but not modeled as tasks because they are not robot-performed:

- Nurse collecting the sample.
- Nurse inserting sample data into the tracking system.
- Laboratory personnel picking samples.
- Authorized human personnel opening drawers.

### Important modeling decision
The text says samples can be picked by **robotic arm or laboratory personnel**. This is not modeled as an OR decomposition because the laboratory personnel option is zero-robot and must be excluded. Therefore, the robot-only model keeps the robotic arm branch.

### Fallback
No FALLBACK relation is used because the description does not specify a failure-triggered ordered alternative such as “if the robotic arm fails, then personnel pick the sample.” The word “or” appears, but it is not explicitly a failure fallback.

## 5. Logical relationships

- **G1 -> G2, G5, G8, G11 [AND][sequential: `G2;G5;G8;G11`]**
  - **Justification:** The mission requires preparation, transport, authorized drawer access, and robotic laboratory processing. These are all mandatory and naturally ordered.

- **G2 -> G3, G4 [AND][sequential: `G3;G4`]**
  - **Justification:** The robot needs delivery/sample information before completing physical preparation at the patient floor.

- **G3 -> AT1, AT2 [AND][sequential: `AT1;AT2`]**
  - **Justification:** The delivery request is received first, then the robot retrieves the associated sample/barcode data.

- **G4 -> AT3, AT4 [AND][sequential: `AT3;AT4`]**
  - **Justification:** The robot must be positioned at the patient floor before verifying the locked drawer for transport.

- **G5 -> G6, G7 [AND][parallel: `G6#G7`]**
  - **Justification:** Secure transportation and time tracking are both required. Timing can be tracked while the robot is transporting the sample.

- **G6 -> AT5, AT6 [AND][parallel: `AT5#AT6`]**
  - **Justification:** The robot can move toward the laboratory while monitoring that the drawer remains locked.

- **G7 -> AT7, AT8 [AND][sequential: `AT7;AT8`]**
  - **Justification:** The robot first obtains the collection timestamp, then records delivery time and evaluates elapsed time against protocols.

- **G8 -> G9, G10 [AND][sequential: `G9;G10`]**
  - **Justification:** Authorization and location validity must be checked before the drawer is opened.

- **G9 -> AT9, AT10 [AND][parallel: `AT9#AT10`]**
  - **Justification:** Robot identity authorization and location authorization are both required and can be checked independently.

- **G10 -> AT11, AT12 [AND][sequential: `AT11;AT12`]**
  - **Justification:** The drawer must be unlocked before its contents can be presented to the robotic arm.

- **G11 -> G12, G13, G14 [AND][sequential/parallel: `G12;(G13#G14)`]**
  - **Justification:** Samples must first be picked and barcode-identified. After that, secure logging and sorting/loading can proceed in parallel.

- **G12 -> AT13, AT14 [AND][sequential: `AT13;AT14`]**
  - **Justification:** The robotic arm picks a sample and then scans its barcode, matching the described action order.

- **G13 -> AT15, AT16 [AND][sequential: `AT15;AT16`]**
  - **Justification:** Pickup time/location must be captured before a secure log record can be written.

- **G14 -> AT17, AT18 [AND][sequential: `AT17;AT18`]**
  - **Justification:** The sample must be sorted before it is loaded into the appropriate analysis-machine entry-module.
