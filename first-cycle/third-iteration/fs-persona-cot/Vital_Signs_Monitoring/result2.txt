## Mission Modeling Rationale (brief)

The mission has a main objective: **periodically check all patients' vital signs using available robots while respecting timing, safety, and exception constraints**.

Main modeling decisions:

* **Achieve goals** are used when the mission requires reaching a world state (e.g., all patients checked, high-risk patients completed).
* **Perform goals** are used when the robot must execute an action (e.g., sterilize, approach patient, send alert).
* **Query goals** are used when information must be obtained from the environment (e.g., room occupation, patient identity).

The mission contains several mandatory activities connected by conjunctions ("and", "therefore", "once"), so most decompositions are **AND**.

Fallback is used when the description explicitly defines recovery behavior:

* patient unavailable → return after 5 minutes.
* insufficient battery → recharge and reassign tasks.
* failed vital sign collection → ask questions, then alert if no response.

# Logical Relationships

### G1 -> G2, G3, G4, G5 [AND][sequential]

* **Justification:** The mission requires identifying patients, executing checks, handling exceptions, and maintaining constraints.

### G2 -> G6, G7 [AND][sequential]

* **Justification:** Rooms must be known before identifying the patient inside.

### G3 -> G8, G9, G10 [AND][sequential]

* **Justification:** Interaction preparation occurs before measurement, and completion occurs after checking.

### G4 -> G11, G12 [AND][parallel]

* **Justification:** Failed measurements and patient non-response are independent failure scenarios.

### G5 -> G13, G14, G15 [AND][parallel]

* **Justification:** Time constraints, robot availability, and sterilization can be monitored independently.

### G7 -> AT2, AT3 [OR]

* **Justification:** The patient can be identified either by asking or barcode scanning.

### G8 -> G16, AT6, AT7 [AND][sequential]

* **Justification:** The robot must physically reach the patient before communication.

### G9 -> G18, G19, G20 [OR]

* **Justification:** The required vital signs depend on the patient's medical condition.

### G11 -> AT15, AT16 [AND][FALLBACK(AT15,AT16)]

* **Justification:** Questions are attempted after failure; retry is an alternative recovery action.

### G14 -> AT19, AT20 [AND][FALLBACK(AT19,AT20)]

* **Justification:** Additional robots are assigned first; if impossible, the manager is alerted.

### G15 -> AT21, AT22 [AND][parallel]

* **Justification:** Both sterilization situations are independent safety requirements.
