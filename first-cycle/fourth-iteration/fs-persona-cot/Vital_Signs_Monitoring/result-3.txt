## Modeling rationale

The mission has five main layers:

1. **Mission cycle objective**: every two hours, all occupied-room patients must have vital signs checked.
2. **Planning and feasibility**: start with the assigned robot; add robots if needed; alert the site manager if no robot combination can finish on time.
3. **Temporal priority**: high-risk patients must be checked in the first 15 minutes.
4. **Room-level procedure**: before entering, check patient availability and battery; identify the correct patient; approach, announce, instruct, collect signs, and mark done.
5. **Exception and hygiene handling**: unavailable patient causes a five-minute return; low battery causes recharge and reassignment; failed vital-sign collection causes questions; non-response alerts nurse/doctor; infectious-room exit requires sterilization; patient contact requires actuator disinfection. These requirements come directly from the mission description. Texto colado

## Logical relationships with justifications

- **G1 → G2, G3, G6, G21 [AND][`G2;FALLBACK((G3;G6),G21)`]**  
  **Justification:** The mission first needs information, then a feasible plan, then execution. If planning/execution cannot be achieved by any robot combination, the site manager must be alerted.

- **G2 → AT1, AT2, AT3, AT4 [AND][parallel]**  
  **Justification:** Occupied rooms, patient categories, robot assignment, and battery/capability data are all jointly required for planning. These are information-retrieval tasks, so they may be obtained in parallel.

- **G3 → G4, G5 [AND][`FALLBACK(G4,G5)`]**  
  **Justification:** The assigned robot is attempted first because the description names “the assigned robot.” Additional robots are only used if mission completion in the required time is impossible.

- **G4 → AT5, AT6 [AND][sequential]**  
  **Justification:** A route must be built before it can be validated.

- **G5 → AT7, AT8 [AND][sequential]**  
  **Justification:** Helper robots must be assigned before validating the multi-robot plan.

- **G6 → G7, G8 [AND][sequential]**  
  **Justification:** High-risk prioritization must be established before executing the room-checking queue.

- **G7 → AT9, AT10, AT11 [AND][sequential]**  
  **Justification:** The queue is built, robots are dispatched to high-risk rooms, and the 15-minute requirement is monitored.

- **G8 → G9, G12, G13, G14, G17 [AND][sequential]**  
  **Justification:** The room-level workflow follows the mission order: pre-entry checks, patient identification, interaction, vital-sign assessment, and completion/hygiene.

- **G9 → G10, G11 [AND][sequential]**  
  **Justification:** Both patient availability and battery sufficiency are mandatory before the robot enters and performs room tasks.

- **G10 → AT12, AT13 [AND][`FALLBACK(AT12,AT13)`]**  
  **Justification:** Availability is checked first. Returning in five minutes happens only if the patient is unavailable.

- **G11 → AT14, AT15, AT16 [AND][`FALLBACK(AT14,(AT15;AT16))`]**  
  **Justification:** Battery sufficiency is checked first. If insufficient, recharge and reassignment are triggered.

- **G12 → AT17, AT18 [OR][parallel-capable alternatives]**  
  **Justification:** The room may have multiple beds, so correct patient identification is required. Asking and barcode scanning are alternatives; either one can satisfy the identification goal.

- **G13 → AT19, AT20, AT21 [AND][sequential]**  
  **Justification:** The robot must approach, announce the procedure, and then provide instructions.

- **G14 → G15, G16 [AND][sequential]**  
  **Justification:** The robot must know which vital signs are required before assessing them.

- **G15 → AT22, AT23, AT24, AT25 [AND][parallel then sequential]**  
  **Justification:** Infectious disease, post-surgical condition, and diabetes history are checked as condition inputs. The required vital-sign set is built after those checks.

- **G16 → AT26, AT27, AT28 [AND][`FALLBACK(AT26,FALLBACK(AT27,AT28))`]**  
  **Justification:** The explicit recovery chain is: collect the sign; if collection fails, ask questions; if the patient does not respond, alert nurse/doctor.

- **G17 → G18, G19, G20 [AND][sequential]**  
  **Justification:** After checking, the patient is marked done, required hygiene is performed, and the robot proceeds to the next room.

- **G19 → AT31, AT32, AT33 [AND][exit then conditional parallel hygiene]**  
  **Justification:** Sterilization is required after coming out of an infectious-disease room, while actuator disinfection is required after patient contact. These hygiene actions are conditionally required and can be handled after room exit.

- **G21 → AT36, AT37 [AND][sequential]**  
  **Justification:** The system should establish that no robot combination can complete the mission before alerting the responsible site manager.
