## Assumptions and notation

`n` = maximum number of robots available for the site.  
`occupied_rooms` = all occupied hospital rooms.  
`high_risk_patients` = patients marked high risk.  
“Conditional AND” means all applicable branches must be satisfied for the patient’s condition profile. For example, if a patient is both infectious and diabetic, the infectious-disease vital signs and glucose must both be checked.

## Logical relationships and justifications

**G1 -> G2, G39 [AND][FALLBACK(G2, G39)]**  
**Justification:** The primary intention is to complete the mission. Alerting the manager is only pursued if the mission cannot be completed by any robot combination, so this is a fallback relation.

**G2 -> G3, G6, G9 [AND][sequential]**  
**Justification:** The system must first secure a feasible robot allocation, then plan the room order, then execute room checks. These are complementary mission phases.

**G3 -> G4, G5 [AND][FALLBACK(G4, G5)]**  
**Justification:** The assigned robot allocation is attempted first. If it cannot meet the required time, additional robots are assigned and tasks are reassigned.

**G6 -> G7, G8 [AND][sequential]**  
**Justification:** The system must know which rooms and patients are involved before building the route and timing plan.

**G7 -> AT5, AT6 [AND][sequential]**  
**Justification:** The mission requires both occupied-room discovery and high-risk patient identification.

**G8 -> AT7, AT8 [AND][sequential]**  
**Justification:** The high-risk-first constraint must be integrated before finalizing the complete two-hour checking route.

**G9 -> G10, G18, G21, G24, G35 [AND][sequential]**  
**Justification:** For each occupied room, the robot must prepare entry, identify and prepare the patient, determine required signs, collect them, and close the visit.

**G10 -> G11, G12, G15 [AND][G11;(G12#G15)]**  
**Justification:** The robot must first reach the room. Availability and battery checks are both required before entry and can be treated as parallel pre-entry checks because the mission does not impose an order between them.

**G12 -> G13, G14 [AND][FALLBACK(G13, G14)]**  
**Justification:** Patient availability is checked first. If the patient is unavailable, the robot returns in 5 minutes.

**G15 -> G16, G17 [AND][FALLBACK(G16, G17)]**  
**Justification:** Battery sufficiency is checked first. If insufficient, recharge and reassignment are required.

**G18 -> G19, G20 [AND][sequential]**  
**Justification:** The robot must identify the correct patient before approaching, announcing, and instructing that patient.

**G19 -> AT19, AT20 [OR][parallel/no fixed priority]**  
**Justification:** The mission states the robot may identify the patient either by asking or by barcode scanning. One successful method is enough.

**G21 -> G22, G23 [AND][sequential]**  
**Justification:** The patient’s condition profile must be known before activating the relevant measurement branches.

**G23 -> AT26, AT27, AT28 [Conditional AND][parallel]**
