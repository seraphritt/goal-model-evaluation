### Logical Relationships

- **G1 -> G2, G6 [AND][(parallel)]**: The mission execution requires both collection and delivery phases to be completed. Multiple robots can execute these phases in parallel (#).
- **G2 -> AT1, AT2, AT3 [AND]**: The collection phase consists of navigating, requesting, and retrieving resources sequentially (;).
- **G3 -> G4, G5 [FALLBACK]**: If battery is low (G4), recharge; otherwise continue (G5).
- **G6 -> AT4, AT5 [AND]**: The delivery phase consists of navigating and delivering resources sequentially (;).
- **G7 -> G8, G9 [FALLBACK]**: If battery is low (G8), return to checkpoint; otherwise continue (G9).
- **G8 -> AT7 [AND]**: Returning to checkpoint involves navigating to the checkpoint.
- **G8 -> G10 [AND]**: If failure to return to checkpoint occurs, alert manager is triggered.
- **G10 -> AT8 [AND]**: Sending alert involves the alert action.
- **G2 -> G3 [AND]**: Collection phase includes battery check.
- **G6 -> G7 [AND]**: Delivery phase includes battery check.
- **G4 -> AT6 [AND]**: Recharging involves navigating to recharge station.
- **G8 -> AT7 [AND]**: Checkpoint return involves navigating to checkpoint.
