### Goal Model Decomposition

Below is the hierarchical decomposition of the mission description into a goal model using AND/OR decompositions and runtime annotations.

---

### **Goal Nodes**

| Name | Text | Runtime | Goal Type | Relation |
|------|------|---------|-----------|----------|
| G1   | Manage Resource Collection and Delivery | - | Achieve | NA |

**G1 is the root goal representing the overall mission. It decomposes into two sub-goals:**

---

### **Sub-Goals of G1**

| Name | Text | Runtime | Goal Type | Relation |
|------|------|---------|-----------|----------|
| G2   | Successfully collect resources from storage locations | - | Achieve | AND |
| G3   | Deliver collected resources to the specified location | - | Achieve | AND |

---

### **Sub-Goals of G2 (Collection Phase)**

**G2 decomposes into sub-goals that represent the steps required for collecting resources.**

| Name | Text | Runtime | Goal Type | Relation |
|------|------|---------|-----------|----------|
| G4   | Navigate to storage locations in an optimal order based on waiting time and path length | - | Achieve | OR |
| G5   | Request and retrieve specific resources from each storage location | - | Achieve | AND |

---

### **Sub-Goals of G3 (Delivery Phase)**

**G3 decomposes into sub-goals that represent the steps required for delivering resources.**

| Name | Text | Runtime | Goal Type | Relation |
|------|------|---------|-----------|----------|
| G6   | Transport collected resources to the specified location in multiple runs as needed | - | Achieve | AND |

---

### **Task Nodes**

**Tasks are actionable steps that represent concrete operations performed by robots.**

#### **Tasks under G4 (Navigate to Storage Locations)**

| Name | Text | Runtime | Relation | Location | Number of Robots |
|------|------|---------|----------|-----------|------------------|
| AT1  | Navigate to the first storage location in the optimal order | - | AND | Storage A | 1 |
| AT2  | Navigate to the second storage location in the optimal order | - | AND | Storage B | 1 |

#### **Tasks under G5 (Request and Retrieve Resources)**

| Name | Text | Runtime | Relation | Location | Number of Robots |
|------|------|---------|----------|-----------|------------------|
| AT3  | Send a message to the storage requesting specific resources | - | AND | Storage A | 1 |
| AT4  | Wait for resources to be retrieved from the storage | - | AND | Storage A | 1 |

#### **Tasks under G6 (Transport Resources to Destination)**

| Name | Text | Runtime | Relation | Location | Number of Robots |
|------|------|---------|----------|-----------|------------------|
| AT5  | Transport resources to the specified delivery location in one run | - | AND | Delivery Point | 1 |
| AT6  | Repeat transport runs as needed to deliver all resources | - | AND | Delivery Point | 1 |

---

### **Runtime Annotations and Relationships**

- **G2 -> G4, G5 [AND]**
  - The collection phase requires both navigating to storage locations (G4) and requesting/retrieving resources (G5).
  
- **G4 -> AT1, AT2 [OR]**
  - The robot can navigate to either the first or second storage location, depending on the optimal order.

- **G5 -> AT3, AT4 [AND]**
  - Retrieving resources from a storage requires sending a request (AT3) and waiting for retrieval (AT4).

---

### **Summary**

The goal model is structured as follows:

1. **Root Goal**: G1
   - Decomposes into:
     - G2: Collection Phase
       - G4: Navigate to storage locations (OR decomposition)
         - AT1, AT2: Tasks for navigating to each storage location.
       - G5: Request and retrieve resources (AND decomposition)
         - AT3, AT4: Tasks for requesting and retrieving resources.
     - G3: Delivery Phase
       - G6: Transport resources to the destination (AND decomposition)
         - AT5, AT6: Tasks for transporting resources.

The model ensures that all steps are completed in a coordinated manner, with fallback mechanisms for battery constraints and failure scenarios.
