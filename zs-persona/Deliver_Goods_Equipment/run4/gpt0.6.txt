**Goal Model – Multi‑Robot Resource Delivery Mission**  
*(Depth‑first numbering – G1, G1.1, …; AT1, AT2, …)*  

| **Name** | **Text** | **Runtime** | **Goal Type** | **Target Condition / Enquired Info** | **Relation** |
|----------|----------|-------------|---------------|--------------------------------------|--------------|
| G1: Fulfill Resource Delivery Mission | Deliver requested resources from storage to the requesting agent at the specified location, handling battery, failures, and parallelism. | (G1.1; G1.2; G1.3) | Perform | – | AND |
| G1.1: Collection Phase | Execute all collection activities: plan order, request resources, monitor battery. | (G1.1.1; G1.1.2; G1.1.3) | Perform | – | AND |
| G1.1.1: Plan Collection Order | Compute the optimal sequence of storages based on waiting time + path length. | - | Perform | – | – |
| G1.1.2: Request Resource | Send request to a storage for the required items and wait for retrieval. | - | Perform | – | – |
| G1.1.3: Monitor Battery (Collection) | Continuously monitor battery; if < 10 % return to recharge and hand off mission. | - | Perform | – | – |
| G1.2: Delivery Phase | Execute all delivery activities: transport, monitor battery, checkpointing, hand‑off. | (G1.2.1; G1.2.2; G1.2.3; G1.2.4) | Perform | – | AND |
| G1.2.1: Deliver Resource | Carry retrieved resources from storage to the destination location. | - | Perform | – | – |
| G1.2.2: Monitor Battery (Delivery) | Continuously monitor battery; if < 30 % return resource to checkpoint. | - | Perform | – | – |
| G1.2.3: Return Resource to Checkpoint | Move the resource to a checkpoint for safe hand‑off. | - | Perform | – | – |
| G1.2.4: Assign Remaining Task to Another Robot | Notify central control to hand over the remaining delivery to a fresh robot. | - | Perform | – | – |
| G1.3: Failure Handling | Respond to failures such as failed checkpoint return. | (G1.3.1; G1.3.2) | Perform | – | AND |
| G1.3.1: Trigger Alert | Generate an alert when the robot cannot return the resource to the checkpoint. | - | Perform | – | – |
| G1.3.2: Report to Sector Manager | Send a detailed failure report to the sector manager. | - | Perform | – | – |
