### Goal Model Summary

#### Goals

| Name | Text | Runtime | Goal Type | Relation |
|------|------|---------|-----------|----------|
| G1 | Execute Resource Collection and Delivery Mission | - | Achieve | - |
| G2 | Collect Required Resources from Storage | - | Achieve | AND with G3 |
| G3 | Deliver Collected Resources to the Specified Location | - | Achieve | AND with G2 |
| G2.1 | Collect Resources without Battery Constraint | - | Perform | OR with G2.2 |
| G2.2 | Recharge and Assign Mission to Another Robot | - | Perform | OR with G2.1 |
| G3.1 | Deliver Resources without Battery Constraint | - | Perform | OR with G3.2 |
| G3.2 | Return Resources to Checkpoint and Assign Remaining Task | - | Perform | OR with G3.1 |

### Logical Relationships

- **G1 -> G2, G3 [AND]**
- **G2 -> G2.1, G2.2 [OR]**
- **G3 -> G3.1, G3.2 [OR]**
- **G2.1 -> AT1.1, AT1.2, ... [Parallel]**
- **G3.1 -> AT3.1, AT3.2, ... [Parallel]**
- **G2.2 -> AT2.1 [Sequential]**
- **G3.2 -> AT3.9 [FALLBACK]**

This goal model ensures that the mission is executed efficiently, with robots collecting and delivering resources in parallel where possible, and handling battery constraints and failures gracefully.
