  • The delivery phase is handled by either the normal delivery branch (G3.1) or, if necessary, the battery‐low handling branch (G3.2).

- **G3.1 → AT5, AT6 [AND]**  
  • Normal delivery requires sequentially navigating to the delivery location (AT5) and then delivering the resource (AT6).

- **G3.2 → AT7, AT8, AT9 [AND with fallback]**  
  • When battery drops below 30%, the robot must return the resource to a checkpoint (AT7) and reassign the remaining delivery (AT8). If returning fails, AT9 is triggered to alert the sector manager.

──────────────────────────────
Additional Note
──────────────────────────────
• In scenarios where multiple items are required from different storages, multiple robots can be assigned so that several instances of G2 and G3 run in parallel. This design can be extended by replicating the goal model for each resource and coordinating through a higher‐level multi-robot coordination goal.

This model is intended as a starting point and may be refined based on further mission details or system constraints.
